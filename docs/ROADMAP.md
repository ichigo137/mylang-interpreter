# Roadmap

## Phase 0 — Foundation (current)
- [x] Lexer and source positions
- [x] Parser and AST
- [x] Tree-walk interpreter
- [x] Variables, constants, expressions, control flow, functions and closures
- [x] CLI file runner and basic REPL
- [x] Examples, written grammar, and automated tests
- [x] Run tests on the target machine and fix any failures

## Phase 1 — Usability
- [ ] Better multi-line REPL input and syntax highlighting
- [ ] Arrays, indexing, and maps
- [ ] Standard library and built-in type/collection helpers
- [ ] More comprehensive runtime source traces
- [ ] Coverage report and edge-case tests

## Phase 2 — Developer experience
- [ ] Formatter and linter
- [ ] VS Code syntax highlighting
- [ ] Language Server Protocol (LSP)
- [ ] Module/import system and package manifest

## Phase 3 — Performance and safety
- [ ] Benchmark suite
- [ ] Bytecode compiler and virtual machine
- [ ] Explicit resource limits for untrusted programs
- [ ] Decide whether static types are part of the language

## Phase 4 — Release engineering
- [ ] Semantic versioning and compatibility guarantees
- [ ] CI on supported Node versions
- [ ] Release notes, contribution guide, license choice, and security policy
- [ ] Packaged standalone executable if distribution warrants it
